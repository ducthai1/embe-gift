🔑 Kết nối GitHub chưa kết nối

Chỉ cần làm 1 lần trên mỗi máy. Token chỉ lưu trên máy này, không nằm trong code.

Cách lấy token (1 phút)
  1. Mở trang tạo token, đặt tên tuỳ ý, thời hạn tuỳ ý.
  2. Repository access → Only select repositories → chọn embe-gift.
  3. Permissions → Repository permissions → Contents → chọn Read and write.
  4. Bấm Generate token, copy rồi dán vào ô dưới.
